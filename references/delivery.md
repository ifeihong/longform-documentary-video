# 验收与发布

## 从工程到成片

1. 先跑类型检查及时间线检查：媒体路径有效，镜头区间、章节边界、字幕和音画对齐，确认受保护文案、音轨和时长。对叙事切点、人物入退、地图、双人卡和片尾抽取实际合成图。分镜表和程序规则不代替合成检查。
2. 长片按章节或帧段渲染并记录起止帧、源与素材指纹、输出帧数。重跑只复用指纹与区间均匹配的片段。时间线改动可能使所有下游运镜或切点偏移，重生成受影响审查帧再做编码对照。核实拼接帧率和边界。
3. Remotion 渲染、审查和预览使用隔离的素材缓存或公共目录。遇到 EPIPE、Target closed 或 WebSocket 关闭，先核对进程退出状态、章文件、帧数和指纹；共享缓存或浏览器压力过高时隔离、降并发，再重跑缺段。遇到现代语法解析失败先核对实际 Node 路径和版本。音频被遗漏时用媒体探测验证流与时长，回查最终合并映射。
4. 用 ffprobe 核对编码、画幅、尺寸、帧率、帧数、时长和音轨。用 FFmpeg 全片解码，区分异常黑屏和计划内淡黑。抽取最终编码帧检查章节边界、人物状态、地图、字幕与片尾，与同版合成帧对照。浏览器以实际播放时间推进和跳转完成作为证据，避免固定短延时造成误判。
5. 可编辑工程包含入口、时间线源、依赖说明、项目字体、引用素材、音频和导出命令。检查 ZIP CRC、引用资产齐全、入口版本与实际可打开性；保留旧版本，最终链接指向存在且验证过的版本文件。记录未实测的环节。秦片 V14 的帧数、审查样本量和分辨率是案例数据，各项目依时长和复杂度制定抽查范围。

## 平台发布物料

- 正文根据同一成片分别包装。抖音可用叙事反差，正文开头兑现标题；小红书提供可检索的实体词和实用章节索引；视频号可用作品的历史影响与讨论价值。标题、首句、封面与成片内容一致。
- 输出每平台可直接复制的标题、正文、主题标签。需要时附备用标题、置顶评论、章节时间与复盘方案。章节时间从最终时间线提取。用公开来源核实会变化的平台规则，区分可验证机制、编辑策略和账号实测。遇到 403 或仅有搜索摘要时标清证据范围，不推断内部权重或固定流量池。
- 按实际要求制作不同封面比例。秦片分别交付 3:4 和 4:3，两种构图单独排版。检查缩略图辨识度、脸部与主标题安全区、文字准确性、图像解码及精确比例。发布页裁切和账号时长限制按实际入口核对。
- 汇总许可与署名、素材出处和艺术复原说明。涉及 AI 生成时，按现行规则核对平台声明选项。将已验收成片、工程、图片和可复制文案交给用户。只有明确授权才实际发布。
